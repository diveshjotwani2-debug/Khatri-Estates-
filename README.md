# Khatri Estates

Website for Khatri Estates, a real estate broker agency in Bhubaneswar, Odisha.

Static site: open `index.html` in a browser. Pages: `index.html`, `privacy.html`, `terms.html`. Images and videos are in `assets/`.

Before launch: connect a custom domain, connect the enquiry form to an inbox, and fill the `[LEGAL BUSINESS NAME]` and `[CONTACT EMAIL]` placeholders in `privacy.html` and `terms.html`.
