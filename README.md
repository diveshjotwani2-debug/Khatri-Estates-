# Khatri Estates

Website for Khatri Estates, a real estate broker agency in Bhubaneswar, Odisha. Static HTML, CSS and JavaScript, hosted on GitHub Pages.

- Pages are plain HTML files at the repository root. Shared styles are in `assets/css/styles.css` and scripts in `assets/js/main.js`.
- Photos and videos are in `assets/img` and `assets/video`.
- To switch enquiries from Instagram to WhatsApp, put the number in `assets/js/config.js`.

Before launch: connect a custom domain, replace `[LEGAL BUSINESS NAME]` and `[CONTACT EMAIL]` in `privacy.html` and `terms.html`, and add the Odisha RERA registration number if it applies.
